# Engineering Mastery Dojo

Mastery-based, fundamentals-first engineering learning. GitHub is the durable source of truth for assignments, reviews, evidence and retests.

## Guardrails
- Preserve historical Issues, assessments and Git history.
- All skills remain Not Assessed until supported by independent evidence.
- Do not award Mastered for one answer or AI-generated implementation.
- The current learning checkpoint is Java Foundations: initial independent coding in IntelliJ IDEA, following reference/pass-by-value retest in chat; this checkpoint has **not yet been persisted as assessed GitHub evidence**.
- No fixed career deadline and no automatic capstone starts.
